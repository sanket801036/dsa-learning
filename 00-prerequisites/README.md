# Phase 0 — Prerequisites

Things to finish **before** starting DSA questions.
If these are weak, every DSA problem will feel like memorising instead of understanding.

Suggested time: 3 to 4 weeks if you give 2 hours a day.

| # | Topic | Folder | Why it matters |
|---|---|---|---|
| 1 | Python basics | [01-python-basics](01-python-basics) | You cannot solve a problem if you fight the syntax |
| 2 | Maths | [02-maths](02-maths) | Primes, GCD, mod and bits show up everywhere |
| 3 | Complexity | [03-complexity](03-complexity) | Interviewers always ask "what is the time complexity?" |
| 4 | Built-in data structures | [04-builtin-ds](04-builtin-ds) | dict and set turn O(n^2) into O(n) |
| 5 | Recursion | [05-recursion](05-recursion) | Trees, graphs, backtracking, DP all sit on it |
| 6 | Basic algorithms | [06-basic-algorithms](06-basic-algorithms) | These are the patterns most questions reuse |

Do them in order. Each folder has its own checklist.
