# DSA Learning

My DSA learning journey in **Python**.

Plan is simple: first finish the prerequisites, then do the 75 must-do questions.
No jumping straight to LeetCode. Build the base first.

## Roadmap

| Phase | Folder | What |
|---|---|---|
| 0 | [`00-prerequisites/01-python-basics`](00-prerequisites/01-python-basics) | Python syntax, loops, functions, strings |
| 1 | [`00-prerequisites/02-maths`](00-prerequisites/02-maths) | Primes, GCD, modular math, bit manipulation |

| 6 | [`01-blind75`](01-blind75) | The 75 questions |

## How to use this repo

1. Open the folder for the current phase.
2. Read its `README.md` — it has the topic checklist.
3. Write code in that folder, one file per topic.
4. Tick the checkbox when done.
5. Commit and push.
